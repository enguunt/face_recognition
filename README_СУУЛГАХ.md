# FACEVISION — Сурагч удирдах + 09:15-аас хойш хоцорсон ирц

Энэ багц нь таны **аль хэдийн ажиллаж байгаа FACEVISION төслийн** нэмэлт өөрчлөлт. Нүүр таних алгоритм, камерын worker, Python орчныг орлуулахгүй.

## 1. Нөөц хуулах

Одоогийн төслийн хавтас `C:\FaceRecognition\face_recognition` дахь **facevision_light_minimal.py**, **attendance_excel.py** файлаа эхлээд өөр хавтас руу нөөцөлж авна. Хэрэв Git дээр өөрчлөлтүүдтэй бол `git status`-аар шалга.

## 2. Нэмэх болон солих файлууд

| Энэ багцаас | Төслийн үндсэн хавтас дахь үйлдэл |
|---|---|
| `facevision_light_minimal.py` | Хуучныг солино |
| `attendance_excel.py` | Хуучныг солино |
| `student_manager.py` | ШИНЭЭР нэмнэ |
| `FACEVISION.spec` | **Зөвхөн Mac .app** багцалдаг бол хуучныг нөөцлөөд солино |

**`camera_stream.py`-г солихгүй**: таны Windows/Mac камерын засвар энэ файлд бий. `facevision.py`, `recognition_policy.py`, `facevision_config.py`, `frame_metrics.py`, `main.py`, `register.py`, `recognize.py`, `dataset/`, `.venv/` зэргийг хэвээр хадгална.

## 3. Windows дээр ажиллуулах

VS Code PowerShell Terminal-д:

```powershell
cd C:\FaceRecognition\face_recognition
.\.venv\Scripts\python.exe -m pip install openpyxl
.\.venv\Scripts\python.exe -m py_compile facevision_light_minimal.py attendance_excel.py student_manager.py
.\.venv\Scripts\python.exe facevision.py
```

### GUI ашиглалт

1. **Камер нээх** → **Нүүр таних**: танигдсан сурагч Excel-д автоматаар бүртгэгдэнэ.
2. **＋ Бүртгэх**: тусдаа, зайтай цонх нээгдэнэ. `Бүртгэл эхлүүлэх` → `Зураг авах` → `Алгасах` / `Зогсоох`. Камерын дүрс үндсэн цонхонд хэвээр харагдана.
3. **Сурагчдын бүртгэл**: идэвхтэй сурагчид, бүртгэлийн зураг тоог харна. `Нэр солих`, `Бүртгэлээс хасах`, `Сэргээх`, `Шинэчлэх` товчтой.
4. **Excel шинэчлэх**: хуудас нээлттэй байснаас өмнө хадгалалт амжилтгүй болсон бол Excel-ийг хааж байгаад дахин дарна.
5. **Өдрийн ирц дуусгах**: ирээгүй сурагчдыг улаан болгоно.

## 4. Өнгө болон хоцролтын зааг

| Цаг | Excel төлөв | Өнгө |
|---|---|---|
| 09:15:00 хүртэл | Ирсэн | Ногоон |
| 09:15:01 ба түүнээс хойш | Хоцорсон | Шар |
| Ирц үргэлжилж байгаа, таниулаагүй | Хүлээгдэж буй | Саарал |
| Ирц дууссан, таниулаагүй | Ирээгүй | Улаан |

Хоцролтын заагийг өөрчлөх бол `attendance_excel.py` дахь:

```python
LATE_AFTER = clock_time(9, 15, 0)
```

### Ирц хадгалах байршил

`facevision_config.py`-д заасан `DATASET` хавтасны **эцэг хавтас** дотор:

```text
Documents/FACEVISION/
  dataset/                 # Идэвхтэй бүртгэлийн нүүрний зураг
  deleted_students/        # Хассан сурагчдын сэргээх нөөц
  attendance_data.json     # Ирцийн үндсэн өгөгдөл
  attendance.xlsx          # Огноо бүрээр, өнгөт Excel
```

**Өдөрт давхар ирц бичихгүй.** Нүүрийг анх баталгаатай таньсан цагийг ашиглана. Нэр солиход тухайн өдрийн ирц нэрийн хувьд дагаж шинэчлэгдэнэ, өмнөх өдрүүдийн ирцийн түүхийг өөрчлөхгүй. Бүртгэлээс хасахад сурагч өнөөдрийн идэвхтэй жагсаалтаас алга болно; өмнөх ирцийн JSON түүх арилахгүй. Устгал нь зориуд **сэргээж болох хасалт**: зургийг бүр мөсөн устгахгүй, `deleted_students/` рүү шилжүүлдэг.

**Биометрийн өгөгдөл:** `dataset/`, `deleted_students/`, `attendance.xlsx`, `attendance_data.json`-г нийтийн GitHub репо руу бүү push хий. Төгссөн/гарсан сурагчдын зураг хадгалах хугацааны бодлоготой бай.

## 5. Хэрэв хуучин `.exe` ажиллуулж байгаа бол

Python файл солигдсон ч хуучин `.exe` автоматаар шинэчлэгдэхгүй. Эхлээд Python хувилбараа ажиллуулж шалгаад дараа нь Windows дээр PyInstaller-ээр дахин build хийнэ. `FACEVISION.spec` нь **macOS .app**-ийн тохиргоо тул Windows-д тэр spec-ийг шууд ашиглахгүй.

## 6. Хязгаарлалт

- Камерын FPS, DeepFace-ийн таних хурд, нарийвчлалыг өөрчлөөгүй.
- Excel файл нээлттэй үед Windows write lock үүсвэл JSON хадгалж болох ч Excel update амжилтгүй байж болно. Excel-ийг хаагаад `Excel шинэчлэх` дар.
- Сурагчдыг хасах/сэргээх болон нэр солих үед танилтын боловсруулалт явагдаж байвал дуусахыг хүлээж байж өөрчилнө.
- Шинэ боломжуудыг синтакс, headless GUI болон хиймэл ирцийн өгөгдлөөр тестэлсэн; **таны бодит камераар** энэ багцыг ажиллуулж үзээгүй.
