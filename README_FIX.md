# FACEVISION — Зассан хувилбар (Windows 11)

Энэ хавтас нь ирц, бүртгэл, камераар таних Python эх кодын зассан хувилбар юм. **Бэлэн Windows EXE биш**. Windows дээр өөрийн `.venv` орчноор шалгаад `build_exe_windows.bat` ашиглан EXE үүсгэнэ.

## 1. Өгөгдлөө хамгаал

Эхлээд FACEVISION болон Excel-ийг хаана. Төслийн `C:\FaceRecognition\face_recognition` хавтсаа бүхэлд нь нөөцөл. Ялангуяа дараах хавтсыг **устгахгүй**:

```text
C:\Users\Dell\Documents\FACEVISION\
    dataset\                нүүрний зургууд
    deleted_students\       сэргээж болох хуучин бүртгэл
    attendance_data.json    үнэн зөв ирцийн үндсэн файл
    attendance.xlsx         өнгөт Excel тайлан
```

Эдгээр нь анхнаасаа төслийн үндсэн кодоос тусдаа хадгалагддаг. `face_embeddings_cache.json` шинээр нэмэгдэнэ — энэ нь хувийн биометрийн өгөгдөл бөгөөд олон нийттэй хуваалцаж болохгүй.

## 2. Шинэчилсэн файлаа суулгах

1. `FACEVISION_FIXED.zip`-ийг задлана.
2. ZIP доторх `FACEVISION_FIXED` хавтасны **бүх файлыг** (тэр дундаа `embedding_cache.py`, `attendance_excel.py`, `student_manager.py`, `tests`) `C:\FaceRecognition\face_recognition` рүү хуулж, давхардсан `.py` файлуудыг солино.
3. **`.venv`, `dataset`, `deleted_students`, `attendance_data.json`, `attendance.xlsx` файлуудаа солихгүй, устгахгүй.**
4. VS Code → Terminal (PowerShell):

```powershell
cd C:\FaceRecognition\face_recognition
.\.venv\Scripts\python.exe -m pip install openpyxl
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe facevision.py
```

Нүүр таних бусад сангууд одоогийн `.venv`-д ажиллаж байвал бүгдийг дахин суулгах шаардлагагүй. `requirements.txt` нь шинэ орчин босгох үед ашиглах жагсаалт, яг таны Python хувилбарт тулгасан бүрэн lockfile биш.

Мөн `start_windows.bat` дээр 2 дарж Python GUI-г ажиллуулж болно (өмнөх `.venv` хэвийн үед).

## 3. Яаж ашиглах вэ?

- **Камер нээх** → **Нүүр таних**: бүртгэлтэй хүмүүсийн вектор эхний удаа бодогдоно, дараагийн удаа өөрчлөгдөөгүй зурагнуудын кэш ашиглагдана.
- **＋ Бүртгэх** → нэр → **Бүртгэл эхлүүлэх** → **Зураг авах**: 4 өнцөг × 3 зураг авч дуусмагц шинэ нэр таних мэдээлэлд *автоматаар* ачаалагдана. 0 зурагтай бол шинэ нүүр танигдахгүй.
- **Сурагчдын бүртгэл** → нэр солих / бүртгэлээс хасах / сэргээх: өнөөдрийн идэвхтэй жагсаалт Excel рүү шинэчлэгдэнэ. Өмнөх өдрүүдийн ирцийг өөрчлөхгүй.
- **Нүүр таних** үед хүний нэр баталгаажихад тухайн өдрийн анхны ирсэн цаг JSON-д хадгалагдаж, Excel тайлан шинэчлэгдэнэ. Давхар ирц нэмэгдэхгүй.
- **Excel шинэчлэх**: JSON мэдээллээс Excel-ийг дахин үүсгэнэ. **Өдрийн ирц дуусгах**: ирээгүй хүнийг улаан болгоно.

Хоцорсон ирц: `09:15:00` хүртэл **цагтаа**, `09:15:01`-ээс **хоцорсон**. Ирсэн — ногоон, хоцорсон — шар, хүлээгдэж буй — саарал, ирээгүй — улаан.

## 4. Excel нээлттэй үеийн WinError 5

Excel нь нээлттэй байгаа `.xlsx` файлыг Windows дээр түгждэг. **Програм өөр програмын файлын түгжээг хүчээр тайлах боломжгүй.** Засвар нь:

1. Ирцийг хамгийн түрүүнд `attendance_data.json`-д хадгална.
2. `attendance.xlsx` түгжээтэй бол `attendance_pending.xlsx` гэсэн боломжтой хуулбар үүсгэнэ (бас түгжээтэй байвал цагийн тэмдэглэгээтэй тусдаа хувилбар үүсгэнэ).
3. 4 секунд орчим тутам Excel файл чөлөөлөгдсөн эсэхийг автоматаар шалгаад үндсэн `attendance.xlsx`-ийг JSON-оос сэргээн шинэчилнэ.

**Үндсэн Excel-ийг хаах хүртэл нээсэн хуучин хүснэгтийн харагдац шууд шинэчлэгдэхгүй.** JSON хамгийн найдвартай эх сурвалж. Шинэ ирц хүлээж байвал pending файл эсвэл JSON-г харж болно. Excel-ийг хаасны дараа үндсэн файл автоматаар шинэчлэгдэх ёстой; шаардлагатай бол **Excel шинэчлэх** дар.

## 5. EXE дахин гаргах (зөвхөн Windows дээр)

**Хуучин EXE Python код шинэчлэгдсэнийг мэдэхгүй.** Python хувилбар ажиллаж байгааг шалгасны дараа:

1. `build_exe_windows.bat` дээр 2 дар.
2. Амжилттай бол `dist\FACEVISION\FACEVISION.exe` гарна.
3. Найздаа явуулахдаа **`dist\FACEVISION` хавтсыг бүтнээр ZIP** болгоно. Зөвхөн EXE-г дангаар нь салгаж явуулж болохгүй.
4. Хэрэв суулгасан DeepFace жингүүд `%USERPROFILE%\.deepface\weights` дотор байвал build script тэдгээрийг багцална. Байхгүй бол шинэ компьютер дээр model анх татагдахдаа интернет шаардаж болно.

EXE үүсгэх явц TensorFlow/DeepFace/PyInstaller-ийн хувилбараас хамаарна. Энэ Linux орчинд Windows GUI, камер болон Windows EXE-г бодитоор турших боломжгүй тул тэнд хэрэглэхэд гарч болох нэмэлт dependency алдааг баталгаатай үгүйсгэхгүй.

## 6. Тест

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тестүүд нь **хувийн зургууд хэрэглэхгүй**, өөрөө түр хавтас үүсгэж Excel болон JSON-г шалгана. Бодит камертай тест тусдаа, Windows компьютер дээр хийгдэх шаардлагатай.

## 7. Ямар файлыг юунд ашиглах вэ?

| Файл | Зориулалт |
|---|---|
| `facevision.py` | GUI эхлүүлэх, EXE entry point |
| `facevision_light_minimal.py` | GUI, бүртгэл, нэр, таних горим, ирцийн холбоос |
| `attendance_excel.py` | JSON болон Excel, түгжээний нөхөн сэргээх логик |
| `embedding_cache.py` | Дахин ачаалахад FaceNet векторыг кэшлэх |
| `student_manager.py` | Нэр солих, хасах, сэргээх |
| `camera_stream.py` | Камер болон MediaPipe worker |
| `recognition_policy.py` | Нэр таних баталгаажуулалт |
| `facevision_config.py` | Хувийн өгөгдлийн байрлал |
| `main.py` | GUI-г нээх өөр нэртэй эхлүүлэгч |
| `camera_demo.py` | Өмнөх камер илрүүлэх дан жишээ |
| `register.py`, `recognize.py` | Terminal-ийн тусдаа хувилбарууд |
| `build_exe_windows.bat` | Windows EXE build |

**Нууцлал:** Нүүрний зураг, танилтын вектор, ирцийн JSON болон Excel-ийг нийтийн GitHub репо, олон нийтэд тавьсан ZIP файлд бүү оруулаарай. Нүүрний өгөгдөл авахдаа сурагчдын зөвшөөрөл, хадгалалтын бодлогоо мөрдөнө.
